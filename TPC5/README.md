**Descrição:** Criar uma aplicação para a gestão de alunos de uma turma, nesta aplicação, no monitor aparece o seguinte menu de operações:
  
    - 1: Criar uma turma;
    - 2: Inserir um aluno na turma;
    - 3: Listar a turma;
    - 4: Consultar um aluno por id;
    - 8: Guardar a turma em ficheiro;
    - 9: Carregar uma turma dum ficheiro;
    - 0: Sair da aplicação
No fim de executar a operação selecionada, a aplicação coloca novamente o menu e pedir ao utilizador a opção para continuar.
